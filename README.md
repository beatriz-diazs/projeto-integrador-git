# Portfólio Pessoal — Beatriz Dias

## Sobre o projeto

Este projeto consiste em um portfólio pessoal desenvolvido para apresentar minha trajetória como estudante de Informática, minhas habilidades em tecnologia e alguns dos projetos realizados durante minha formação.

O site foi criado como parte do Projeto Integrador Final do curso **Fundamentos de Git e GitHub — CEFET-MG**, com o objetivo de aplicar na prática os conhecimentos de desenvolvimento web e controle de versão.

## Funcionalidades

- **Apresentação pessoal:** introdução e informações sobre minha formação.
- **Sobre mim:** descrição da minha trajetória na área de tecnologia.
- **Habilidades:** apresentação das linguagens e ferramentas que estou aprendendo.
- **Projetos:** exibição de trabalhos e atividades de programação.
- **Navegação interativa:** menu com links para as diferentes seções.
- **Destaque de navegação:** indicação da seção selecionada no menu.
- **Animações:** efeitos de entrada conforme as seções aparecem na tela.
- **Design responsivo:** adaptação do layout para diferentes tamanhos de tela.
- **Acessibilidade:** melhorias na navegação por teclado e na estrutura dos elementos HTML.

## Pré-requisitos

Para visualizar e executar o projeto, é necessário:

- Um navegador atualizado, como Google Chrome, Firefox ou Microsoft Edge.
- Git instalado, caso queira clonar o repositório.
- Um editor de código, como Visual Studio Code, para visualizar ou modificar os arquivos.

Não é necessário instalar bibliotecas ou dependências externas.

## Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/beatriz-diazs/projeto-integrador-git.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd projeto-integrador-git
   ```

3. Abra o arquivo `index.html` em um navegador.

Também é possível abrir a pasta do projeto diretamente no Visual Studio Code e utilizar uma extensão como Live Server para visualizar as alterações durante o desenvolvimento.

## Desenvolvimento com Git e GitHub

Durante o desenvolvimento, foram utilizados recursos do Git e GitHub para organizar e acompanhar as alterações do projeto, incluindo:
