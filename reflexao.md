# Reflexão sobre o aprendizado de Git e GitHub

## 1. Conceitos mais complexos aprendidos

Durante o curso, alguns conceitos exigiram mais atenção e prática:

### Branches e ramificações

Aprender a trabalhar com branches foi um dos desafios, principalmente entender como criar ramificações para desenvolver funcionalidades sem modificar diretamente a branch principal. Com a prática, percebi como essa organização facilita o desenvolvimento de projetos.

### Merge e Pull Requests

Compreender a integração de alterações entre branches também foi desafiador. Aprendi que os Pull Requests permitem revisar e discutir modificações antes de incorporá-las ao projeto principal, tornando o trabalho mais organizado.

### Controle de versão e Conventional Commits

Aprender a registrar as alterações por meio de commits e utilizar o padrão Conventional Commits exigiu atenção. Entendi a importância de escrever mensagens claras para facilitar a identificação do que foi modificado em cada etapa.

## 2. Recursos que posso aplicar imediatamente

1. **Git:** utilizar comandos como `git add`, `git commit`, `git push`, `git pull` e `git switch` para controlar as versões dos meus projetos.

2. **GitHub:** organizar projetos por meio de repositórios, branches, Issues e Pull Requests, inclusive em atividades realizadas em grupo.

3. **Conventional Commits:** utilizar mensagens padronizadas para manter o histórico de alterações mais claro e organizado.

## 3. Dúvidas que ainda permanecem

- Como resolver conflitos de merge de maneira mais eficiente quando diferentes pessoas modificam as mesmas partes de um arquivo?
- Em quais situações é mais adequado utilizar rebase em vez de merge?
- Como organizar um fluxo de trabalho com Git e GitHub em projetos maiores, com vários colaboradores?

## Considerações finais

O desenvolvimento deste projeto permitiu colocar em prática os conhecimentos adquiridos durante o curso. Além de aprender novos comandos, compreendi melhor a importância do controle de versão, da organização do código e da colaboração no desenvolvimento de software.

Pretendo continuar utilizando Git e GitHub nos meus próximos projetos, aprimorando minhas habilidades e explorando recursos mais avançados dessas ferramentas.
